# Retired Prehistoric Pixel Art Direction

This document previously described the portfolio's square-grid prehistoric artwork. That design has been replaced by the organic geometric mosaic visual system.

The current authoritative specification is [ORGANIC_GEOMETRIC_MOSAIC_DESIGN.md](ORGANIC_GEOMETRIC_MOSAIC_DESIGN.md). It documents the exact palette, the quilted-fabric inspiration, organic and angular geometry, project mappings, interaction and motion behavior, accessibility, responsive rules, and provenance boundaries.

Some source file paths and exported component names still contain `pixel` for import compatibility. Those names do not describe the rendered artwork. Do not recreate the retired square-pixel geometry when editing them.

The previous specification remains available in Git history for historical reference.
